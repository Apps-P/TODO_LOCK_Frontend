# TodoLock 작업 컨텍스트

2026-09-16에 사용자 제공 초기 요구사항(v1.2, 2025-11-08)과 현재 코드를 대조해 작성했다. 기준 커밋은 `95284fe`이며 조사 시작 시 추적 파일 변경은 없었다.

- [requirements.md](requirements.md): 초기 요구사항을 기능별로 정리한 기준. 원문의 표 깨짐을 정리한 요약이며 원문 전체 복사본은 아니다.
- [code-review.md](code-review.md): 코드 구조, 데이터 모델, 요구사항별 구현 현황, 문제와 후속 작업.
- [verification.md](verification.md): 실행한 검사와 검증 한계, 후속 재현 시나리오.

이번 작업 범위는 코드 조사와 이 디렉터리의 문서 작성이다. 앱 소스나 초기 명세의 정책은 변경하지 않았다. 문서의 개선 제안은 확정된 제품 결정이 아니다.

다음 작업에서는 `code-review.md`의 우선 확인 항목부터 읽고 실제 코드 변경 여부를 다시 확인한다. 특히 초기 명세의 JSON 저장과 현재 Hive 저장, 긴급 해제 정책, Android/iOS 범위는 서로 구분한다. 구현 존재를 실기기 동작 성공으로 취급하지 않는다.

`.env`, 서명 파일, 토큰과 사용자 데이터는 이 문서에 복사하지 않았다. 이 디렉터리는 저장소 내부 프로젝트 기록이며 사용자 전역 메모리와 별개다.
