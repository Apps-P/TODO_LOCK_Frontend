# 초기 요구사항 기준

출처: 사용자가 2026-09-16 대화에 제공한 「Never give up 요구사항 명세서」 v1.2.
원문 작성일: 2025-11-08. 작성자: 한유승, 양한결. 프로젝트명: TodoLock.

## 목적과 범위

디지털 디톡스와 TODO 앱을 결합한다. 대상은 TODO 앱 이용자와 디지털 디톡스 사용자이며 목표 플랫폼은 Android/iOS다. 핵심은 TODO CRUD와 Job 시작 시 화면 잠금이다.

초기 역할표에서 TODO CU/RD, 화면 잠금, 앱바·캘린더, 테마·공유 컴포넌트·폴더 구조 담당은 Yuseung Han으로 기재되어 있다. 별도의 디자인 및 데이터베이스 명세서는 이번 대화에 첨부되지 않았다.

## 기능 요구사항

| ID | 우선순위 | 요구사항 |
| --- | --- | --- |
| FR-001 | 상 | 내용, 소요 시간, 잠금 여부 등 Job 생성/수정. 수정 시 기존 값 로드. 필수 입력 누락 시 경고하고 저장 차단. 로컬 JSON 저장. 잠금 선택 시 오버레이 권한 확인 및 설정 안내. 설정 이동 전 권한 설명 팝업 권장. |
| FR-002 | 상 | 날짜별 목록과 생성 화면 이동. 왼쪽 스와이프 삭제 및 DB 반영. Job 클릭으로 수정. 시작 전 흰색, 진행 중 주황색, 완료 회색. 체크 시 현재 시각을 check_time에 저장하고 재체크 시 null로 복귀. 경과 시간이 duration에 도달하면 done=1. |
| FR-003 | 상 | 메인 앱바의 오늘/내일 토글, 햄버거 메뉴, 캘린더 날짜 선택으로 해당 날짜 목록 이동. 설정 메뉴는 UI만 있어도 됨. 주별 진행도 표시는 선택 사항. |
| FR-004 | 상 | 잠금 Job 시작 시 지정 시간 동안 오버레이로 다른 앱 접근 제한. 시작 알림 및 2차 확인. 미허용 권한 안내. 긴급 해제는 1회 2분, 무료 3회, 추가 1달러 결제. 잠금 중단 시 남은 시간/진행률 표시. |
| FR-005 | 하 | 완료 데이터를 바탕으로 업적 달성 판정(예: 3일 연속 완료 → 작심삼일), 달성 팝업, 업적 목록, 로컬 JSON 상태 저장, 이미지 템플릿을 통한 SNS 공유. 목록 UI는 차후 적용 예정이라고 기재. |
| FR-006 | 하 | 긴급 해제 시 1차 확인 이미지와 취소 버튼, 2차 강화 이미지 모달. 두 단계 통과 후 해제. 횟수 초과 시 해제 불가 및 메시지. |

## 원문 내 확인이 필요한 정책

1. FR-002의 Job 클릭은 수정, FR-004의 Job 클릭은 잠금 시작으로 기술되어 있다. 현재 코드는 체크박스로 시작하고 별도 편집 아이콘으로 수정한다. 이 조작 방식의 채택 여부는 미확정이다.
2. FR-004는 무료 횟수 초과 후 결제를 허용하지만 FR-006은 횟수 초과 시 해제 불가라고 기술한다. 유료 해제가 예외인지 확인이 필요하다.
3. 무료 해제 3회의 초기화 단위(각 Job, 하루, 계정 등)는 명시되지 않았다.
4. 잠시 해제 중 Job 시간이 계속 흐르는지, 완전 포기 시 상태를 초기화할지 실패 기록을 남길지는 명시되지 않았다.
5. 현재 Hive 저장, Supabase 동기화, 인증, 광고, 동작하는 권한 설정은 초기 명세와 차이가 있거나 추가된 구현이다. 현재 코드에 존재한다는 이유만으로 초기 요구사항을 수정하지 않는다.

이 항목들은 향후 해당 기능을 수정할 때 판단할 사항이다. 이번 문서화 작업을 막는 질문이나 확정된 정책은 아니다.
